Réglages d’économie Facebook

Trois réglages à faire une seule fois. Ils empêchent Facebook de télécharger des vidéos que vous ne regardez pas.

0 sur 3 réglages faits

1. Arrêter la lecture automatique

Sans ce réglage, les vidéos se téléchargent toutes seules quand vous faites défiler le fil.

  1. Ouvrez Facebook, puis le menu (les trois traits).
  2. Paramètres et confidentialité, puis Paramètres.
  3. Préférences, puis Média.
  4. Dans Lecture automatique, choisissez l’option « jamais » (ne jamais lancer les vidéos automatiquement).

2. Activer l’économiseur de données

Facebook affiche alors les vidéos dans une qualité plus légère.

  1. Au même endroit : Paramètres, Préférences, Média.
  2. Dans Qualité vidéo, choisissez « Économiseur de données ».

3. Couper les données en arrière-plan

Facebook ne télécharge plus rien quand vous ne l’utilisez pas.

  1. Appuyez sur le bouton ci-dessous : les informations de l’application Facebook s’ouvrent.
  2. Cherchez « Données mobiles » ou « Utilisation des données ».
  3. Désactivez les données en arrière-plan.

Les noms des menus peuvent changer un peu selon la version de Facebook et le modèle de téléphone. Les économies dépendent de votre usage : elles ne sont pas garanties.

Test technique : sonde DNS

Réservé aux essais. La sonde note les noms de domaine que Facebook demande. Elle ne bloque rien. Le bouclier est arrêté pendant le test : réactivez-le ensuite.

  1. Appuyez sur « Démarrer la sonde ».
  2. Ouvrez Facebook : regardez 3 vidéos, puis faites défiler des photos pendant 3 minutes.
  3. Revenez ici, appuyez sur « Arrêter », puis sur « Partager le rapport ».
